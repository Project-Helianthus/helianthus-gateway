## GraphQL serves driver-declared typed views

The generic namespace engine now serves each typed view a driver declares in its namespace as a query field named `<namespace>_view_<root record>` that takes the `instance` that declared it. The GraphQL types carry exactly the declared record names, field names, types, nesting and units (the unit is the field description), and each field reads the member the driver bound to it from the same cut, with no bus request. A view with no earlier GraphQL type is served with all its declared fields. A declared scalar other than `String`, `Int`, `Float` or `Boolean`, or one record name declared with two shapes, fails the build of the namespace fields instead of being served. The introspection golden and the root field list are unchanged (#1775).
