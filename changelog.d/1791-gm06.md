## Order the evaluation times of concurrent contributors in the semantic hub test

`TestMultiSourceControlConcurrentContributorCycles` stamped the two contributors of one shared asset from two independent counters, so a publish could be evaluated before the other contributor's last evaluation and the hub correctly refused it, which sometimes lost a control event in the test. The test now takes one shared stamp under one lock for each publish and fence. The hub's check is unchanged. Test only; the gateway binary is unchanged.
