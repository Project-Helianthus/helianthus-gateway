## Serve the host cut on portal, metrics and graph reads

The portal catalog takes rows from the served cut by resource id, and the semantic index admits native members from the namespace registry. The host action invoker and revalidator are installed on the gateway catalog and the mounted contribution handler. Metrics open the runtime-state directory and keep the slot lock until shutdown. Local GraphQL, remote GraphQL and MCP read the host tree, so one served cut answers the four semantic reads with the same canonical bytes. (#1795)
