## Assemble the gateway on the SemReg host core

The gateway process opens the SemReg host after its runtime state is loaded and passes that state's directory to the host. Each configured driver option keeps its name and its effect as host enablement: an enabled option is an enabled host instance and a disabled option stays disabled. The three SemReg mapping gates name the same SemReg revision the gateway requires, and that revision contains the host core.
