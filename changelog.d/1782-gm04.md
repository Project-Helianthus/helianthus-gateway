## Prove the generic MCP method call delivers key and arguments to the driver and returns its result

A gateway test drives `driver_method_call` against a stub driver that registers method keys, records each call and returns a fixed result. The method keys, arguments and results come from one vector file, and each case asserts the key and input the driver received and the result the caller got back. The stub imports no protocol package. This is the gateway half of the proof that heating setters are callable through the generic member keys; no production code, boundary exception or dependency pin changes.
