## Resolve reserved driver hooks to host surfaces

A registered driver declares the semantic, mcp, portal, setup and evidence hooks at version 1 on any direction. Each declared hook resolves to the host surface for that name: publication through the host runtime, the namespace roster of the host tree, portal manifests and actions, a native setup procedure on an instance or transport node, and a diagnostic member read. The northbound output hook stays a single declaration at version 1 and still resolves as unknown. (#1794)
