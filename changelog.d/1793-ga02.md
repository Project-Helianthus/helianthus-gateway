## Read trusted certified joins and carry configured identity links

The gateway reads the optional host-local certified joins of the operator-record file from the trusted configuration root and hands them to the host as typed statements. A certify, rebind or revoke names the action, the exact pair, the survivor and the revision; a revoke also names the certification revision. The trusted loader binds the origin evidence. The declaration cannot supply that evidence, and no response returns the host-local section. An ordinary replacement writes the accepted host-local section back unchanged. A configured identity link still waits for the owning driver's next batch, is carried with the audit of the accepted records, and is withdrawn on the next eligible batch after the record is removed.
