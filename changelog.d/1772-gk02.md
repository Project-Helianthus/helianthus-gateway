## The remote GraphQL listener serves the four graph reads

The remote machine-to-machine GraphQL listener answers four more fixed documents, `SemanticResources`, `SemanticTraversal`, `SemanticLens` and `SemanticElementCatalog`, with the canonical record the local schema returns for the same request and cut, and the client gains the matching reads. Each read has one optional provider in the handler configuration. Every other operation still answers `QUERY_REJECTED`, and the three current documents, their golden and the per-host request budget are unchanged.
