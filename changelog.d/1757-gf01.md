## Count identifier register selectors and standalone native constants

The protocol-boundary check records a register composite whose address is an identifier, including the other selector fields in that composite, and each identifier in a uint16 list of register constants. It also records a standalone byte, uint8 or uint16 constant in a file that already has a deletion row. Those rows are debt, so changing one fails the check until its ledger line changes with it. A ledger line for a row that already exists at the base revision can be added; a row introduced by the change cannot.
